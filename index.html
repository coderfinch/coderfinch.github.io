FinchEdit

Experience the innovative code editor FinchEdit. From software flow analysis to intuitive user interface, FinchEdit provides a comprehensive development environment. The editor provides syntax highlighting, code assist and deeper insights into data flow. Integrated with DefChecker, a static source code analyzer tool to enhance software quality.

UI Views

Text View

Open file from local file system, edit and save changes back to filesystem. Syntax highlighting and view function/variable declaration.

Output View

The Output View shows the list of undefined variables observed in currently opened .c file in Text View.

Flow Graph View

The Flow Graph View shows the control flow of the last function in the currently opened .c file in Text View.

Analysis

Data Flow analysis

Flow sensitive analysis is performed on source code of .c file and included headers. The analysis runs on each function in a translation unit and outputs uninitialized variables.

Pointer-Alias analysis

The points-to analysis is performed to find uninitialized/undefined pointers. Interprocedural analysis is performed for call sites that resolve to functions in the same translation unit.

How it works?

Scenario - 1

  • Open the source file to be analyzed in Text View
  • Hover over variable/function name to see declaration
  • Click Run from menu
  • View the results in Output View tab
  • Switch to Flow Graph View tab to view the flow graph

Scenario - 2

  • Click menuitem File->Open Sample->Open Sample 1
  • Text View tab shows contents of selected sample
  • Switch to Flow Graph View tab to view Control Flow Graph
  • Click menuitem File->Run
  • Output View shows the list of undefined variables

Prerequisites

  • Install Microsoft Visual C++ 2015-2022 Redistributable (x64)
  • Qt 6.8.3 (using LGPL license)
  • Source code is available at https://www.qt.io/development/download-open-source
  • The libraries are packaged along with the application
  • Built using Visual Studio 2022 (64-bit) version 17.14.15 and Qt 6.8.3

Code snippet

Input 


                                Line 1: void f1() {
                                Line 2:     int b;
                                Line 3:     int c=5;
                                Line 4:     int sum = b+c;
                                Line 5: }
                                Line 6: int main() {
                                Line 7:     f1();
                                Line 8: }

Output

Undefined variable b in Line 4 : sum = b+c

Input 


                                Line 1: void f4() {
                                Line 2:     int *q;
                                Line 3:     int a = *q;
                                Line 4: }
                                Line 5: int main() {
                                Line 6:     f4();
                                Line 7: }

Output

Undefined variable q in Line 3 : a = *q
Undefined variable *q in Line 3 : a = *q
